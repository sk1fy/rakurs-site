# Ракурс — редизайн rkrs.ru

Полноценный адаптивный сайт на React 19, TypeScript и Vite. Визуальная система основана на [ka.rkrs.ru](https://ka.rkrs.ru/): Inter, тёмная сине-графитовая палитра, бирюзовый акцент и оригинальный SVG-знак «Ракурс».

## Запуск

```sh
npm install
npm run dev
```

Проверка и production-сборка:

```sh
npm run build
npm run preview
```

Собранный сайт находится в `dist/`. Vite может выбрать следующий свободный порт, если стандартный занят. Проверенный локальный preview текущего сеанса: http://127.0.0.1:4174/.

## Что реализовано

- Главная с лаконичным текстовым первым экраном, всеми направлениями и реальным снимком «Контроля активности».
- Каталог 20 виджетов: поиск, категории, фильтры в адресной строке.
- 20 продуктовых страниц, исходные URL установки и инструкции.
- Внедрение, лицензии и калькулятор 20% бонусов, партнёрская программа.
- База знаний с шестью исходными инструкциями, FAQ, поддержка, юридические документы и 404.
- Выпадающее меню категорий виджетов, мобильная навигация, FAQ и доступный диалог с собственным селектом и клавиатурным управлением.
- Локальные WOFF2-шрифты и изображения; для внешних ресурсов нет runtime-зависимости.
- Контактный сценарий открывает черновик WhatsApp или Telegram. Сервер отправки заявок и платёжный процесс не подключены.

## Содержание и исследование

[Подробное исследование](docs/RESEARCH.md) охватывает 51 страницу карты сайта и визуальный референс. Исходные тексты и ссылки сохранены в `docs/research/`. Расхождения в ценах и условиях описаны отдельно в исследовании.

- `src/content.ts` — контакты, короткие тексты, категории, FAQ и этапы внедрения.
- `src/data/site-data.json` — проверенные источники: продукты, инструкции, документы.
- `src/components.tsx` — переиспользуемые компоненты и демонстрация CRM.
- `src/pages.tsx` — страницы.
- `src/App.tsx` — маршруты, шапка, футер, метаданные.
- `src/styles.css` — дизайн и адаптивные состояния.
- `src/fonts.css` и `public/assets` — локальные ассеты.

## SSG и проверка SEO

`npm run build` проверяет TypeScript, собирает клиент и SSR-бандл, затем создаёт 36 HTML-страниц и `404.html`. Все страницы содержат контент без выполнения JavaScript. Метаданные и JSON-LD для сборки и клиентской навигации определены в `src/seo.ts`; адреса со слешем на конце нормализуются.

`npm run test:seo` после сборки проверяет все HTML-страницы, sitemap, редиректы и смену метаданных при навигации (включая переходы с юридических страниц и 404). В sitemap входят только 34 индексируемые страницы; `lastmod` не выдумывается из даты сборки.

## Размещение

Загрузите содержимое `dist/` на статический хостинг. Для каждого известного URL сервер должен отдавать соответствующий `<route>/index.html`, для неизвестного — `404.html` с HTTP 404. Не включайте общий SPA-fallback на главную: он создаёт soft 404 и может подменять пререндеренные страницы.

Для Netlify/Cloudflare Pages включён `public/_redirects` с 301 со старых адресов; `404.html` используется как страница ошибки. Для Nginx подготовлен [фрагмент конфигурации](deploy/nginx-rkrs.conf), который нужно включить в `server` с `root`, указывающим на загруженный `dist/`. `_redirects` сам по себе Nginx не настраивает.

После размещения проверяйте HTTP-ответы: `/vnedrenie` и `/kontrol-aktivnosti` — 200 с собственными title и контентом; `/cashback` — 301 на `/bonus`; случайный неизвестный URL — 404. Также проверьте HTTPS, перенаправление www на основной домен, `/robots.txt`, `/sitemap.xml` и доступность `/assets/`. Редиректы `/top` и `/rakurs-free-pack` сохраняют нужную категорию каталога.

`.openai/hosting.json` связывает этот checkout с существующим проектом Sites. Публикация в Sites обновляет адрес `https://rakurs-redesign.sk1fx.chatgpt.site`. Canonical и sitemap рассчитаны на будущий основной домен `https://rkrs.ru`; обновление Sites не переключает DNS rkrs.ru.
