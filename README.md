# Ракурс — редизайн rkrs.ru

Полноценный адаптивный сайт на React 19, TypeScript и Vite. Визуальная система основана на [ka.rkrs.ru](https://ka.rkrs.ru/): Inter, тёмная сине-графитовая палитра, бирюзовый акцент и оригинальный SVG-знак «Ракурс».

## Запуск

```sh
npm install
npm run dev
```

Проверка и production-сборка:

```sh
npm run build
npm run preview
```

Собранный сайт находится в `dist/`. Vite может выбрать следующий свободный порт, если стандартный занят. Проверенный локальный preview текущего сеанса: http://127.0.0.1:4174/.

## Что реализовано

- Главная с лаконичным текстовым первым экраном, всеми направлениями и реальным снимком «Контроля активности».
- Каталог 20 виджетов: поиск, категории, фильтры в адресной строке.
- 20 продуктовых страниц, исходные URL установки и инструкции.
- Внедрение, лицензии и калькулятор 20% бонусов, партнёрская программа.
- База знаний с шестью исходными инструкциями, FAQ, поддержка, юридические документы и 404.
- Выпадающее меню категорий виджетов, мобильная навигация, FAQ и доступный диалог с собственным селектом и клавиатурным управлением.
- Локальные WOFF2-шрифты и изображения; для внешних ресурсов нет runtime-зависимости.
- Контактный сценарий открывает черновик WhatsApp или Telegram. Сервер отправки заявок и платёжный процесс не подключены.

## Содержание и исследование

[Подробное исследование](docs/RESEARCH.md) охватывает 51 страницу карты сайта и визуальный референс. Исходные тексты и ссылки сохранены в `docs/research/`. Расхождения в ценах и условиях описаны отдельно в исследовании.

- `src/content.ts` — контакты, короткие тексты, категории, FAQ и этапы внедрения.
- `src/data/site-data.json` — проверенные источники: продукты, инструкции, документы.
- `src/components.tsx` — переиспользуемые компоненты и демонстрация CRM.
- `src/pages.tsx` — страницы.
- `src/App.tsx` — маршруты, шапка, футер, метаданные.
- `src/styles.css` — дизайн и адаптивные состояния.
- `src/fonts.css` и `public/assets` — локальные ассеты.

## Размещение

Загрузите `dist/` на статический хостинг. Для клиентских маршрутов сервер должен возвращать `index.html`, если файл по адресу не найден. Для Netlify/Cloudflare Pages включён файл `_redirects`. Пример Nginx:

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

Это SPA: заголовки/описания обновляются в браузере. Если потребуется серверная индексация всех страниц без JavaScript, следующий шаг — статический пререндер или SSR. Публичная публикация и замена действующего сайта в этой задаче не выполнялись.
