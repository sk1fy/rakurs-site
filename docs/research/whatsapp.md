Написать в WhatsApp
Стоимость: бесплатно
После установки любая переписка в WhatsApp Web начинается в два клика: выбрать номер и начать диалог. Виджет позволяет вести переписку, не добавляя номер в свой список контактов.
Для того, чтобы отправить,к примеру, коммерческое предложение через WhatsApp, клиента нужно добавить в список контактов. Потом найти как его записал и не перепутать с похожим именем. Это занимает много времени и создает путаницу.
Проблема
Упростить переписку с клиентами и поставщиками, сэкономить время и избавить от лишних записей в телефоне.
Задача
Виджет позволяет начать диалог в WhatsApp Web без добавления контакта в телефон. Достаточно нажать на номер в "аmoCRM" и выбрать "Написать в WhatsApp". Стандартное окно беседы открывается автоматически.

1. Нажмите кнопку
2 В установленных интеграциях "amoCRM" найдите виджет.
3. Для активации виджета введите номер телефона.
4. Настройки не нужны, виджет работает автоматически.
5. Для того,чтобы начать диалог с клиентом, нажмите на его номер телефона в "amoCRM" и в выпадающем списке выберите "Написать в WhatsApp".
6. У Вас откроется веб версия WhatsApp с чатом по данному номеру.
Виджет работает на всех тарифных планах.
