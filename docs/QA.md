# Проверка редизайна

Дата: 29 сентября 2026 года. Проверялся production build через Vite preview.

## Сборка

- `npm run build` — TypeScript и Vite успешно, без предупреждений о размере чанков.
- `npm install` — 0 известных уязвимостей по выводу npm audit.
- Код отформатирован Prettier.
- 20 продуктов: 7 бесплатных, 9 ТОП, 4 ПРО.
- 19 прямых OAuth-ссылок amoCRM из исходных продуктовых страниц. Для одного виджета на модерации — запрос доступности.
- Семь локальных WOFF2-файлов существуют. Все ассеты суммарно около 500 КБ, без исходных тяжёлых TTF.

## Браузер

- 35 основных страниц при 320 px: по одному H1, без горизонтального переполнения после исправлений. Все 20 карточек продуктов и шесть инструкций открываются напрямую.
- При 768 px проверены главная, каталог, внедрение, лицензии, партнёрам, база знаний, «Контроль активности», «Автопоиск дублей» — без переполнения.
- При 1280 px просмотрена главная, включая нижние секции; загружены оба изображения, переполнения нет.
- Мобильные меню и каталог дополнительно проверены при 390 px. Меню закрывается после перехода.
- Каталог: 20 карточек, бесплатный фильтр — 7, запрос Telegram с бесплатным фильтром — 1. Поиск и фильтр сохраняются в URL.
- Калькулятор: 150 000 ₽ → 30 000 ₽ бонусов.
- FAQ раскрывает ответы.
- Контактный диалог открывается/закрывается, выбранная тема и текст корректно кодируются в черновик WhatsApp. Сообщения не отправлялись.
- Страница «Контроль активности»: правильная цена и исходный OAuth client_id.
- Демо CRM: переключение мышью и стрелками клавиатуры, Home возвращает первый таб.
- В финальном production-сеансе консольных ошибок нет.

## Правки по обратной связи

- Удалена демонстрационная CRM из первого экрана; вместо неё лаконичный текстовый hero. Старые проверки демонстрации выше относятся к первой версии.
- Единый компонент CategoryBadge используется в каталоге, карточке рекомендуемого продукта и на продуктовых страницах: контрастные метки «ТОП-виджет», «ПРО-виджет», «Бесплатно».
- Меню «Виджеты»: категории открываются наведением мыши или отдельной кнопкой. Основная надпись остаётся прямой ссылкой на каталог.
- Проверено: ТОП → `/widget_amocrm#top`, 9 результатов; ПРО → `/widget_amocrm#premium`, 4 результата; клик по надписи → `/widget_amocrm`, 20 результатов.
- На мобильном вложенное меню работает и закрывается после перехода.
- Собственный селект в контактном диалоге: иконки, описания, выбранное состояние, управление стрелками, Enter, Home/End и Escape. Escape закрывает сначала список, сохраняя диалог.
- Выбор «Продление лицензий» попадает в черновик WhatsApp. Отправка не выполнялась.
- Первый экран и выбор последнего пункта проверены при 320 px; переполнения нет. В браузере ошибок нет. `npm run build` проходит.
